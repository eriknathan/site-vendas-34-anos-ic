# Explosão Inferno Coral | 34 Anos

Vitrine Next.js (App Router + TypeScript) da Festa Explosão Inferno Coral | 34 Anos, com dados locais de demonstração — sem checkout, pagamento ou coleta de dados reais nesta fase.

## Começando

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000). Veja o passo a passo completo (com e sem Docker) em [`Docs/COMO-RODAR.md`](./Docs/COMO-RODAR.md).
